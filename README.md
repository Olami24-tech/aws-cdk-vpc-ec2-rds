AWS CDK VPC, EC2 & RDS Infrastructure
Overview

This project demonstrates how to provision AWS infrastructure using AWS Cloud Development Kit (CDK) and TypeScript.

The infrastructure is defined as code (IaC), allowing resources to be deployed consistently and repeatably using AWS CloudFormation generated by CDK.
